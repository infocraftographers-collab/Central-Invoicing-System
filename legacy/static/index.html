📊 Google Sheets Real-Time Sync

Automated & 100% Free

You can keep your Google Sheets updated in two ways:
1. Instant CSV Export: Click Download CSV anytime to open or import all records into Google Sheets.
2. Real-time Auto Sync: Enter your Google Apps Script Webhook URL below to automatically append a new row into your Google Sheet every time staff saves an invoice!

📋 Click to see 1-minute Google Sheets Webhook Setup Instructions
1. Open your Google Sheet in your browser.
2. Go to Extensions ➔ Apps Script.
3. Paste this simple 8-line script:
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  sheet.appendRow([
    new Date(), data.firm_id, data.invoice_no, data.invoice_date,
    data.client_name, data.client_gstin, data.sub_total_price,
    data.cgst_amount, data.sgst_amount, data.igst_amount,
    data.round_off, data.grand_total, data.status
  ]);
  return ContentService.createTextOutput(JSON.stringify({"result": "success"})).setMimeType(ContentService.MimeType.JSON);
}
4. Click Deploy ➔ New Deployment, select Web App, set Who has access to Anyone, and copy the Web App URL into the box above!
